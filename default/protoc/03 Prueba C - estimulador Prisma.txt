Prueba C - estimulador Prisma ELA (VIBRAR g_<comando>)
;==============================================================================
; PROTOCOLO DE PRUEBA C  (EEGFX-36)
;
; Recorre todos los comandos del estimulador Prisma ELA de Guillermo
; (Controller_Board v1.0.X, firmware ELA_SW v2.2), primero las pruebas de un
; conector cada vez y después los comandos combinados.
;
; Cada estímulo dura 4 s:
;   - 2 s con la imagen de la zona que vibra (figura gris, zona en negro),
;     mostrada a la vez que se envía el comando;
;   - 2 s de pantalla en blanco, sin estímulo.
;
; NECESITA EL PRISMA conectado por USB. Al cargar el protocolo aparece el
; selector de puertos: elegir el del Arduino en "estimulador Prisma".
; Puerto a 9600 8N1; cada comando viaja como "<comando>\r\n".
;
; Al abrir el puerto el Arduino se resetea: el protocolo espera hasta 2 s antes
; de empezar. Si el PRIMER comando (t_j2, brazo) no se nota, esa espera es
; corta y hay que subir EEGControl.PRISMA_RESET_WAIT_MILIS.
;
; Revisar los puentes de J9 (diafragma) antes de ejecutarlo: según cómo esté
; montada la placa, J9 puede no recibir tensión o activarse junto al brazo.
;
; Comprobar en protocolo-XXXX-XX.log una línea
;   "ENVIADO COMANDO <comando> AL PRISMA"
; por cada VIBRAR, en el mismo orden que aquí.
;
; Ficheros que usa, todos en default/Multimedia/, 800x600:
;   "PRUEBA PRISMA <zona o comando>.png"   figura con la zona en negro
;   "PRUEBA PRISMA blanco.png"             pausa entre estímulos
;==============================================================================
